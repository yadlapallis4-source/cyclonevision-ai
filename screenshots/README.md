## HURSAT Satellite Data Visualization

`hursat_irwin_example.png`

This image shows an example visualization of the IRWIN brightness-temperature data extracted from a NOAA HURSAT-B1 NetCDF file for tropical cyclone SONAMU.

### PoC Status

- Satellite data successfully loaded
- NetCDF file successfully read using xarray
- IRWIN variable successfully extracted
- Latitude and longitude coordinates plotted
- Visualization successfully generated

This is an initial data-processing and visualization PoC. It does not represent a trained prediction or classification model.
