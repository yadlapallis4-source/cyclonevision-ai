## Selected Dataset — NOAA HURSAT-B1

- **Dataset:** NOAA HURSAT-B1 Version 6
- **Provider:** NOAA National Centers for Environmental Information (NCEI)
- **Purpose:** Tropical cyclone satellite imagery analysis
- **Format:** NetCDF
- **Temporal resolution:** 3-hourly
- **Spatial resolution:** Approximately 8 km
- **Coverage:** Global tropical cyclones
- **Planned use:** Initial cyclone pattern classification PoC
- **Status:** Selected, download/subset not implemented yet
- **Official source:** https://www.ncei.noaa.gov/products/hurricane-satellite-data

We will use a small, manageable subset for the initial PoC rather than downloading the complete archive.
